## 历史真实故障

指定录屏在 40:00 截图后出现企业代理 403（netentsec_page_push / HIS Proxy Notification）。PNG 941,748 字节，进入工具结果的 Base64 1,255,664 字节。失败请求记录为原始 1,916,211 字节、zstd 后约 1,209,401 字节；不能仅靠此例区分代理检查的是压缩前还是压缩后大小。

此前 2026-10-20 的无鉴权合成请求记录：999,999 字节得到上游 401；1,000,001 字节得到上述代理 403。401 仅说明未在同一代理步骤被挡住，不代表模型调用成功；恰好 1,000,000 字节的真实代理边界未测。这是该环境的证据，不是 OpenAI 官方统一 1 MB 上传规则。

最后一次成功模型输入 138,266 tokens，运行时窗口 258,400；当次失败没有上下文超长错误证据。没有上传完整 MP4。完整来源与时间戳在随交付报告中，技能不携带原视频。

## 本次合成实验

18 组自动化场景通过。HTTP 大小实验使用临时 127.0.0.1 服务，显式设定 1,000,000 字节阈值；它验证处理流程，不冒充新的生产代理复测。真实模型读取另测 1 张合成代码截图及 3 篇博客插图，工具保留原 JPEG 字节，图片校验码读出正确。

| 场景 | 观测 |
|---|---|
| 中文/emoji/CRLF/引号/反斜杠文本 | 2,800,000 字节，1,270 包，最大 3,155 字节，重组完全一致 |
| 16 个分别小于 1 MB 的文件 | 合并请求 2,212,080 字节被本地网关拒绝；重新拆包最大 2,868 字节 |
| 高噪声 PNG | 11,538,008 → 63,859 字节 JPEG；Base64 85,148 字节 |
| JSON 转义 | 12,000 字节正文成为 24,002 字节 JSON 字符串；按序列化结果拆分 |
| gzip | 重复文本大幅缩小，但 1,100,000 字节随机数据 gzip 后 1,100,358 字节；压缩不是通用语义输入 |
| 累计返回 | 83 包后累计 261,285 字节，继续读取被 262,144 字节预算拦截 |
| 本地缓存 | 删除合成图片副本后，已构造历史仍为 1,725,252 字节并失败；精简交接后的请求为 107,264 字节并通过本地网关 |
| 命令日志 | 2,300,000 字节输出保存在本地，元数据返回仅 254 字节 |
| 文档 | PDF 指定页提取、扫描页识别为需 OCR、DOCX 原生文字、PPTX 关系顺序测试通过 |
| 保护分支 | 重复读取、二进制/编码数据拒绝、图片授权、动画帧选择、锁竞争、篡改校验、交接不重置账本通过 |

256 KiB 累计预算是在补充多图实验后确定的保守默认值；初版 192 KiB 对若干清晰小图过早停止。最终脚本重新跑完累计拦截实验。它衡量经脚本返回/预留的内容，不是最终 HTTP 请求大小。账本不是安全隔离机制，代理仍须遵守同任务不更换账本的规则。

图片存在画质取舍：高噪声图缩小到 800×533；不能据此声称细节无损。技术小字应裁切；目标降到 7 KiB 时，本地博客图在质量下限处拒绝压缩。默认策略无法承诺所有来源都能变成既很小又完整清晰的图片。
